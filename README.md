# Birkan Uysal | Kişisel Web Sitesi

Makine mühendisi Birkan Uysal için hazırlanmış tek sayfalık portfolyo sitesi: hakkımda, eğitim, yetenekler, projeler ve iletişim bölümleri.

## Yapı

```
html/
  index-dark.html        Ana sayfa
  css/custom-fixes.css   Siteye özel düzenlemeler (V5–V10)
  js/custom-fixes.js     Yetenek sürükleme, proje modalları, scrollspy
  modal/contact.php      İletişim formu
  img/                   Görseller ve ikonlar
```

Statik bir site; `html/index-dark.html` dosyasını tarayıcıda açmak yeterli. İletişim formu için PHP destekli bir sunucu gerekir.

## Öne çıkanlar

- Eğitim bölümünde modern bir timeline
- İkonlu, mouse ile sürüklenebilen yetenekler grid'i (SolidWorks, CATIA, Siemens NX, ANSYS, AutoCAD, SAP, Dynamics 365, Canias, PLM/PDM)
- Modal açılan, eşit yükseklikte proje kartları
- Sol menüde aktif bölüm takibi (scrollspy)
- Mobil uyumlu düzen
